# AgentFlow

Futuristic autonomous AI agent workspace with dark command-console UI, chat-first experience, pricing, auth, and a mock AI execution layer.

## Features
- Auth screens: login, register
- Dashboard with conversation sidebar
- AI chat workspace with voice and media buttons
- Research / task simulation
- Pricing page
- Responsive dark futuristic design

## Run locally

```bash
npm install
npm run dev
```

Then open:
- http://localhost:3000
- http://localhost:3000/dashboard
- http://localhost:3000/login
- http://localhost:3000/register
- http://localhost:3000/pricing

## Notes
This is a working local app with a mock backend layer for chat and checkout flows so the experience is runnable without real external API keys.
